# Registro de cambios

## 1.0.0
- Primera versión pública estable de Project Moondancer — Media Manager.
- Nueva sección informativa con ruta de configuración y proporciones recomendadas.
- Aviso explícito de proporción global compartida y compatibilidad limitada a temas integrados.
- Actualización de versión en `extension.yaml` y título de ajustes.
- Documentación consolidada y licencia GNU GPL-3.0-only.
- Incorporación de temas de ejemplo Desktop y Fullscreen como referencias funcionales de integración.
- Eliminación de métodos vacíos heredados de la plantilla, sin alterar los perfiles ni el mecanismo de guardado/cancelación.

## 0.5.0
- Perfiles visuales independientes para Desktop y Fullscreen.
- Migración de las preferencias anteriores al perfil Fullscreen.
